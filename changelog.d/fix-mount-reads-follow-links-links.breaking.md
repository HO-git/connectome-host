- **Operators with links inside a workspace mount:** a recipe's mounts don't follow links, since `RecipeWorkspaceMount` leaves `followSymlinks` out, so on every mount a recipe makes, a file that is itself a link, even one to another file in the same mount, is no longer read. The web UI's `/files/` route answers 403 for it. The instructions module injects nothing for such an instructions file, so agents run without their instructions, and an `instructions-unavailable` alert says so. The activity module no longer takes a typing notice's origin hint from such a file. Replace the link with the file it points to, or open the file by its own path. Unchanged: a file named by its own path is read as before, and so is one reached through a linked directory, as long as it lies inside the mount.
